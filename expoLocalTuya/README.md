# expoLocalTuya

Android app using Expo SDK 56, React Navigation, TypeScript, and Uniwind with Tailwind CSS 4.

## Development

```sh
npm ci
npm start
```

Use an Android development build with `expo-dev-client`. To build in the cloud, use `npx eas-cli@latest build --platform android --profile development` after configuring EAS and a development profile. With a local Android SDK installed, `npm run android` generates and builds the Android project.

`app.json` declares Android as the only supported platform. Native project directories are generated by Expo and ignored by Git; configure native behavior through app config and config plugins.

## Styling

Uniwind is configured in `metro.config.js`. The root `global.css` imports Tailwind CSS and Uniwind and is loaded in `src/App.tsx`. Use `className` on React Native components. Third-party components need Uniwind's `withUniwind` wrapper to accept classes.

Metro generates `uniwind-types.d.ts` in the app root. Start Metro or run an Android export to generate it before the first typecheck if it is missing. Uniwind requires no additional Babel preset or Expo config plugin.

## Native modules

The Expo Modules API runtime is included by `expo`; import its JavaScript APIs from `expo`. Expo Doctor advises against a direct `expo-modules-core` dependency in the application. Create a local module when needed with:

```sh
npx create-expo-module@latest --local
```

For an Android-only module, set its `expo-module.config.json` platforms to `["android"]` and implement its native functionality in Kotlin. Local modules are automatically discovered in `modules/`. Rebuild the Android development client after adding or changing native code.

## Checks

```sh
npm run lint
npm run typecheck
npx expo install --check
npx expo-doctor
```

## Formatting and commits

Run `npm run format` to format the app, or `npm run format:check` to check formatting. Husky is installed automatically by the `prepare` script on `npm install` and `npm ci`.

The Git repository lives in the parent directory. Its pre-commit hook runs in `expoLocalTuya`: lint-staged formats and re-stages the app's staged files with Prettier, preserving unstaged edits, then ESLint checks the entire app. Formatting failures or ESLint errors block the commit; ESLint warnings do not.
